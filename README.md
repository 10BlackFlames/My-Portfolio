# Personal portfolio

A responsive, no-build portfolio website. It uses plain HTML, CSS, and JavaScript, so it runs locally without installing packages.

## Run it

Open `index.html` in a browser. The Google Fonts import needs an internet connection; the page remains usable with system fallbacks when offline.

## Make it yours

1. In `index.html`, change the browser title, description, and the wordmark name (`Toluwani Isaac Olalemi`) to your name or preferred brand.
2. In `script.js`, edit the `projects` array. Each item has a title, category, short description, preview style, and URL. Copy an item to add a project or remove one to take it out. Current project links open in a new tab.
3. The Ignivo button opens its live app. The enquiry links open a pre-addressed email to `isaacolalemi23@outlook.com` with a starter message. Update `contactLinks.email` in `script.js` if that address changes, and add your GitHub and LinkedIn URLs.
4. Update any stack items in the “Tools of the trade” section of `index.html` as your toolkit changes.
5. Replace `assets/toluwani-olalemi.jpg` if you want to use a different portrait.

Splitly and Virtual Museum are live web projects. Last Light and Tidebound: The Drowned Bell are live game projects with optimized screenshot previews in `assets/`. Add more items to the `projects` array in `script.js` as your portfolio grows; set `category` to `Web` or `Games` to include each project in its filter.
